# Como criar uma nova spec

Perguntas que este texto responde: como criar uma nova spec, onde fica o botão Nova spec, como adicionar uma entrega ao projeto, como pedir uma funcionalidade nova, como criar uma especificação, onde descrevo o que quero, o que é o ID da spec.

Uma **spec** descreve uma entrega do projeto, por exemplo "listar todos os usuários com o e-mail mascarado". Cada spec passa por refinamento, execução e validação.

## Passo a passo

Existem três caminhos que levam ao mesmo formulário.

**Pelo cartão do projeto (mais rápido):**
1. Abra **Projetos** no menu lateral.
2. No cartão do projeto, clique em **Nova spec**.

**Pela página do projeto:**
1. Em **Projetos**, clique em **Abrir** no cartão do projeto.
2. No painel **Especificações**, clique em **Nova spec**.

**Pelo chat:** no Chat de dúvidas, escolha o projeto e clique em **Nova spec**.

Nos três caminhos o formulário abre na página do projeto:

1. Em **Descreva o serviço**, escreva em palavras simples o que a entrega deve fazer. Os documentos do projeto entram como contexto; só esta spec passa pelo refinamento.
2. Clique em **Continuar**. O sistema sugere o **ID da spec**: um nome curto em inglês (por exemplo list-users). Você pode editar.
3. Clique em **Começar refinamento**. O sistema abre a tela de refinamento desta spec.

Para desistir, clique no X (Cancelar).

## O que vem depois

Na tela de refinamento você revisa os documentos, clica em **Avaliar**, responde as perguntas dos agentes e, quando tudo estiver atendido, clica em **Iniciar análise**. Veja "refinamento" e "execucao".

## Casos especiais

- Para corrigir algo de uma spec que já foi entregue, use **Relatar problema** na validação (veja "validacao"). Isso reabre a mesma spec com o seu relato.
- Uma spec concluída fica somente leitura. A próxima entrega começa em uma spec nova.
- O chat pode abrir sozinho uma spec de correção quando achar que algo sendo feito contraria a spec. Ela aparece como rascunho em refinamento; nada é executado até você iniciar.
