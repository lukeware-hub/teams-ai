# Como criar ou importar um projeto

Perguntas que este texto responde: como criar um projeto, como começar um projeto novo, como importar um projeto do Git, como adicionar um projeto, onde fica o botão Novo projeto.

Um projeto é o serviço que os agentes vão construir. Ele tem um nome, uma descrição e várias specs (as entregas).

## Criar um projeto novo

1. Abra **Projetos** no menu lateral.
2. Clique em **Novo projeto** (canto superior direito).
3. Escreva o **Nome do projeto** e, se quiser, a descrição com suas palavras. Os agentes usam esse texto para começar o refinamento.
4. Preencha o **ID do projeto**: um nome curto em inglês, só com letras minúsculas, números e hífens (por exemplo order-service). Se preferir, clique em **Sugerir ID com IA** e o sistema propõe o ID e o nome da primeira spec a partir do nome e da descrição.
5. Clique em **Criar projeto**. O sistema abre o refinamento da primeira spec do projeto, na primeira etapa (flow.md). Antes de qualquer documento ser enviado ao Jev, a tela pergunta se o projeto é confidencial.

O projeto só entra na lista de Projetos quando a primeira execução começar. Enquanto isso ele aparece em **Novos projetos em refinamento**.

## Importar um projeto que já existe no Git

1. Em **Projetos**, clique em **Importar do Git**.
2. Em **URL do repositório**, cole o link de um repositório que já tenha o arquivo docs/project.json e confirme. O código é baixado e o projeto entra na lista.

## Excluir

O cartão do projeto tem o botão **Excluir**. Ele pede confirmação antes de apagar.
