# Primeiros passos: conectar o ambiente

Perguntas que este texto responde: como começar, o que preciso configurar, como conectar o GitHub, como entrar no Claude, o que é o Status do ambiente, a tela de configuração inicial.

Na primeira vez, o Teams AI abre a tela **Configure este ambiente**. Ela leva você por estes itens, um de cada vez:

1. **Login do GitHub CLI**: entrar na sua conta do GitHub. Abra o link que a tela mostrar e cole o código.
2. **Organização do GitHub**: escolher onde os repositórios dos projetos serão criados.
3. **Token do GitHub**: a chave que permite criar repositórios e pull requests.
4. **Login do Claude**: entrar na sua conta do Claude. Os agentes usam a sua assinatura.
5. **Chave do OpenRouter (Jev)**: usada pelo Jev, um verificador extra dos documentos.

Quando tudo está conectado aparece **Tudo pronto para começar**. Depois disso, abra **Projetos** e use **Nova spec** ou **Novo projeto**.

## Voltar a esta tela depois

No menu lateral, o ícone **Status do ambiente** (o gráfico) mostra a mesma lista. Use-o quando o login do Claude expirar ou quando você quiser trocar uma chave.
