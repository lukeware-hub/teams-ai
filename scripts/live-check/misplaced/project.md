# Agendamento de consultas

## Visão

Um sistema simples para clínicas pequenas organizarem a agenda de consultas.

## Personas

- Recepcionista: marca, remarca e cancela consultas.
- Paciente: confirma a consulta pelo celular.

## Restrições

- Cada consulta tem um único responsável.
- O banco de dados é PostgreSQL 16.
- O sistema agenda consultas para pacientes de clínicas pequenas.

## Princípios

- Nenhuma consulta é marcada em horário ocupado.
