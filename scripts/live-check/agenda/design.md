# Design

Este projeto não tem interface própria nesta versão: é um serviço de API REST consumido pela tela da recepção, feita por outro time (ver briefing, fora do escopo). Não há tokens visuais, componentes nem telas a especificar aqui.

## Contrato da API para quem faz a tela

- Respostas em JSON, mensagens de erro em português, por campo.
- Datas e horários em ISO 8601 com fuso.
